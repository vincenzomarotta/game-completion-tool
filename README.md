# Game Completion Tool

Carica il salvataggio di un gioco e scopri cosa ti manca per il 100% e dove trovarlo. Tutto gira nel browser: il file non viene caricato da nessuna parte.

Sito: https://vincenzomarotta.github.io/game-completition-tool/

## Giochi

- **Death's Door** (`deaths-door/`): legge `Save_slotN.sav` da `%USERPROFILE%\AppData\LocalLow\Acid Nerve\DeathsDoor\SAVEDATA`. Posizioni e chiavi del salvataggio dalla tabella di [DeathsDoor.ItemChanger](https://github.com/dpinela/DeathsDoor.ItemChanger) (pubblico dominio).

## Aggiungere un gioco

Crea una cartella con il suo `index.html` e aggiungi una card nella home (`index.html`).
